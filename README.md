# Task 1 – Reconnaissance and Vulnerability Scanning

## Objective
The objective of this task was to perform active reconnaissance and vulnerability scanning in a safe and controlled test environment.

## Overview
This task involved gathering information about the target system and identifying open ports, running services, and potential security vulnerabilities. The scanning activities were performed in a controlled environment for learning and security assessment purposes.

## Activities Performed
* Performed active reconnaissance.
* Identified open ports and running services.
* Conducted vulnerability scanning.
* Analyzed the scan results.
* Identified potential security weaknesses.

## Learning Outcome
This task provided practical experience in network reconnaissance and vulnerability assessment and helped in understanding how security professionals identify potential weaknesses in a system.
